Capstone Project

C.A.R.E: Smart Wireless IoT-Enabled Location Tracker for Rapid Emergency Intervention and Real-Time Response for Elderly and Persons with Disability using Arduino Framework

Status: Ongoing

Description

C.A.R.E. (Computerized Auxiliary Response for Elders and PWDs) is an Arduino-based wearable IoT emergency alert system. It has two triggers: a tactile push-button for manual alerts and an ADXL345 accelerometer for automatic fall detection, so help can be called even if the user is unconscious. On activation, the device sends the user’s GPS location and identification to the C.A.R.E. mobile app, family members, and caregivers. It switches between Wi-Fi and GSM so alerts still go out when the internet is down.

Objectives

  • Design a wearable emergency alert device usable by elderly individuals, PWDs, outdoor workers, and people living alone.
  • Implement a dual-trigger system: manual push-button plus automated fall detection.
  • Capture and transmit precise GPS coordinates with each alert.
  • Build a mobile app that sends real-time distress notifications and location updates to family and emergency contacts.
  • Provide a cost-effective alternative to commercial wearable emergency devices.
  • Evaluate functionality, reliability, and response time of the system.

Technologies Used

Hardware: ESP32, NEO-6M GPS, Air780E 4G module, ADXL345 accelerometer, push-button switch, rechargeable battery module

Software: Arduino IDE, React Expo (caregiver mobile app), Next.js (web monitoring interface), Firebase Realtime Database and Authentication, Google Maps API, JSON data format, Visual Studio Code

Communication: Wi-Fi primary, GSM/SMS fallback

Methodology: Agile (three sprints over 14 weeks); Black-Box and White-Box testing; unit, integration, and system testing

Results

The prototype successfully integrated all hardware modules with dual-trigger activation. Hybrid Wi-Fi/GSM switching kept alert latency within 2 to 5 seconds. The system was evaluated against ISO/IEC 25010 quality characteristics by 152 end-users and 31 IT experts, and both groups rated it Strongly Agree / Excellent. Survey reliability (Cronbach’s alpha): 0.970 for end-users and 0.849 for IT experts.
