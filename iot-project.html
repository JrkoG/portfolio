IoT Project

C.A.R.E: An IoT Wearable Device for Real-Time Emergency Alert System

Course: IoT / IoE · Adviser: Dr. Alvin Jason A. Virata

Description

A low-cost wearable emergency device (wristband or pendant) built on an ESP32 microcontroller. With one press of a tactile push-button, it reads the user’s GPS location and sends a distress signal to a companion mobile app and designated emergency contacts. It is designed for elderly individuals, persons with disabilities, outdoor workers, and people living alone, who may not be able to unlock a phone and dial for help during a crisis.

Objectives

  • Design a wearable emergency alert device that is easy to use for elderly people, PWDs, outdoor workers, and people living alone.
  • Implement a simple push-button mechanism to trigger an alert quickly.
  • Integrate location tracking so GPS coordinates are sent with the alert.
  • Send notifications to a mobile application, family members, and emergency contacts.
  • Provide a cost-effective alternative to commercial wearable emergency devices.
  • Evaluate the functionality, reliability, and response time of the system.

Technologies / Components Used

Hardware:

  • ESP32 microcontroller (built-in Wi-Fi and Bluetooth)
  • NEO-6M GPS module
  • SIM800L GSM/GPRS module (SMS fallback)
  • Tactile push-button switch
  • 3.7V Li-Po battery (600–1000 mAh), TP4056 charging module, voltage regulator
  • Buzzer and LED indicator
  • Breadboard and jumper wires (prototype), PCB and wristband enclosure (final)

Software:

  • Arduino IDE (C/C++ firmware)
  • Firebase Realtime Database and Firebase Cloud Messaging
  • Google Maps API
  • React Expo (mobile app)
  • Visual Studio Code and GitHub

How It Works

  • Perception layer: pressing the button wakes the ESP32, which gets the user’s coordinates from the NEO-6M GPS.
  • Network layer: the alert is sent over Wi-Fi to Firebase. If Wi-Fi is unavailable, the SIM800L sends an SMS with a Google Maps link instead.
  • Application layer: the mobile app alerts the guardian and shows the user’s location on a map.
  • The buzzer and LED confirm to the user that the alert was sent.

Output / Result

A working prototype that integrates the ESP32, GPS, GSM, battery, and feedback components with a Firebase-backed mobile app. Testing confirmed alert delivery over both communication paths (Wi-Fi and SMS fallback), GPS coordinate delivery, and local buzzer/LED feedback.
